# GridLock

GridLock is a search engine homepage for you. Custimize with widgets, explore with AI search, and experince the grid.

## Widgets:
- Clock

- Weather
- Quote 
- Iframe
- Note
- Favorite (Website)

Custimize the number of results, remove widgets, activate light mode, and explore recent searches. AI Summaries are powered by Meta's Llama 4 Scout.

You can also clear the widgets in the settings menu, or remove each one mainly by pressing the trash can, then selecting the widget.
